# 照片整理工作手册

## 目标

扫描用户指定的照片集合，按日期或明确的主题分类，将文件复制到目标目录并生成完成报告。始终保留原始文件。

## 操作步骤

### 1. 扫描

1. 如果来源目录或目标目录不明确，先向用户询问。
2. 使用 `list_files` 检查目录；需要递归按名称查找时使用 `search_files`。
3. 统计支持的图片和视频文件、大小及修改时间。不要上传图片或发送到外部服务。
4. 日期或内容不明确时，只用 `read_image` 查看少量样本；不得臆测人物、地点或私人事件。
5. 汇报文件数量、总大小、日期范围和无法读取的文件，再进入分类。

### 2. 分类

1. 优先使用文件名或可用元数据中的可信拍摄日期；只有缺少更可靠日期时才使用修改时间。
2. 默认按 `YYYY/YYYY-MM` 分类。只有信息明确或用户提出要求时，才增加事件或主题子目录。
3. 日期未知的文件放入 `未分类`，不要猜测日期。
4. 先整理来源到目标的映射并提供简要预览。
5. 大批量操作或涉及受保护用户目录时，先列明影响范围并等待用户确认。

### 3. 复制

1. 只在目标位置创建目录，不改动来源集合。需要时可用 `run_powershell` 执行范围明确的目录创建操作。
2. 使用 `copy_file` 复制；本流程禁止使用 `move_file` 或 `delete_file`。
3. 目标文件已存在时禁止覆盖。选择不冲突的名称（如 `照片-2.jpg`），保留扩展名，并记录重命名。
4. 分批复制，逐项检查工具结果；遇到错误应停止并说明，不得将失败说成成功。
5. 核对复制结果和文件数量是否与扫描清单一致。

### 4. 生成报告

1. 在目标目录用 `write_file` 创建 `photo-organizer-report.md`。
2. 报告应包含来源与目标目录、扫描时间、分类规则、按目录和类型统计的数量、重复文件改名、跳过或失败项及核验结果。
3. 不在报告中写入图片内容或统计所不需要的个人信息。
4. 若报告在工具大小限制内，用 `read_file` 读回核验；超出限制时确认文件存在，并向用户说明无法全文回读。
5. 最后总结复制内容和仍待处理的问题。

## 可用工具

- `list_files`、`search_files`：扫描文件和目录。
- `read_image`：必要时查看少量样本。
- `copy_file`：复制文件；`run_powershell`：创建目标目录。
- `write_file`、`read_file`：生成并核验报告。

## 注意事项

- 保留所有原件，不移动、不重命名、不删除或覆盖来源文件。
- 大批量操作或涉及受保护目录时，先请求确认。
- 不从图片中推断敏感人物、地点或事件。
- 明确报告错误和跳过项；只有核验复制结果和报告后才能宣告完成。
